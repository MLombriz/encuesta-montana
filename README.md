# Encuesta — decisiones de compra en turismo de montaña

Instrumento de campo de un trabajo final de maestría (Universidad Torcuato Di Tella).
Experimento de elección discreta sobre preferencias en salidas de montaña guiadas.

La página es estática y autónoma. El diseño del experimento se genera aparte y se
inyecta en el archivo: no se edita a mano.
